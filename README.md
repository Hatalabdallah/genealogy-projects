## 📚 Overview

This repository contains three professional genealogy web applications built with modern web technologies. Each application showcases different aspects of family history research and heritage preservation.

## 🏗️ Projects

| Project | Description | Tech Stack | Live Demo |
|---------|-------------|------------|-----------|
| [**Family Story**](./family-story-ui-main) | Modern genealogy platform for discovering family history | React, TypeScript, Tailwind, Vite | [Demo](https://family-story.ddumba.kyakabi.com) |
| [**Family Weaver**](./family-weaver-ui-main) | Interactive family tapestry creation tool | React, TypeScript, Framer Motion, Vite | [Demo](https://family-weaver.ddumba.kyakabi.com) |
| [**Heritage Hub**](./heritage-hub-ui-main) | Complete heritage management system with AI tools | React, TypeScript, GraphQL, Vite | [Demo](https://heritage-hub.ddumba.kyakabi.com) |

## ✨ Key Features

### 🔧 Common Features Across All Projects
- **Modern Stack**: Built with React 18, TypeScript, and Tailwind CSS
- **Responsive Design**: Mobile-first approach with full responsiveness
- **Component Library**: Custom UI components using ShadCN/UI
- **Performance Optimized**: Fast loading with Vite build tool
- **Developer Experience**: ESLint, Prettier, and TypeScript configured

### 🏡 Family Story Specific
- Interactive family tree builder
- DNA analysis dashboard
- Historical records search
- Photo restoration tools

### 🧵 Family Weaver Specific
- Drag-and-drop family tapestry
- Story timeline visualization
- Collaborative editing
- Media gallery integration

### 🏛️ Heritage Hub Specific
- AI-powered photo enhancement
- Document digitization
- Family timeline generator
- Multi-language support

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm, yarn, pnpm, or bun
- Git

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/ddumbaabdallah/genealogy-projects.git
cd genealogy-projects
```

2. **Choose a project to run**
```bash
cd family-story-ui-main  # or family-weaver-ui-main or heritage-hub-ui-main
npm install
npm run dev
```

3. **Open in browser**
```
http://localhost:8080
```
